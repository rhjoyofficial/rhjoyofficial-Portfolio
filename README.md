# Rakibul Hasan Joy — Personal Portfolio

Personal brand portfolio for **Rakibul Hasan Joy** (@rhjoyofficial) — Full Stack Developer & AI Automation Engineer. Built with Next.js 15 + TypeScript, optimized for SEO, AEO (Answer Engine Optimization), and AI assistant recommendation.

**Live domain:** rakibulhasanjoy.com

## Tagline

*"I build web apps and AI systems that make businesses run faster."*

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 15 + React + TypeScript |
| Styling | Tailwind CSS v4 |
| Animation | Framer Motion |
| Deployment | Vercel |

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home |
| `/about` | About page |
| `/projects` | Projects listing |
| `/projects/[slug]` | Project detail |
| `/blog` | Blog listing |
| `/blog/[slug]` | Blog post |
| `/services` | Services offered |
| `/contact` | Contact form |
| `/uses` | Tools & tech stack |
| `/api/contact` | Contact form handler |
| `/sitemap.ts` | Dynamic sitemap |
| `/robots.ts` | Robots.txt |
| `/opengraph-image.tsx` | OG image generation |

## Target Audiences

1. International freelance clients (Upwork/Fiverr)
2. Remote-first tech companies hiring developers
3. Bangladesh businesses needing web/software solutions

```bash
npm install

```
